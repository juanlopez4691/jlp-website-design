Project card content, no fill, radius or padding (the box belongs to `work-block`). Three parts, top to bottom: head (client name in the `tag` style, uppercase, no pill, 4px gap, then `h3-card`), body (`body-sm`, then one `result` line, 8px gap) and chips. Parts are 16px apart. The body fills the free height, so the chips always sit at the bottom. Holds up to four chips; unused ones are hidden. The client name is plain small caps text.

Variants: `Style` filled (navy text, in a mint box with `radius-lg` and padding 24) and outline (mint text, no result line, in a transparent box with a 1.5px mint border, used for "More work"). The layout is the same at every breakpoint, so there is no `Breakpoint` property: the block sets the width. Penpot name `work-card`. In Astro: `WorkCard` with an `outline` prop.
