Project card content, no fill, radius or padding (the box belongs to `work-block`). Three parts, top to bottom: head (client name in the `tag` style, uppercase, no pill, 4px gap, then `h3-card`), body (`lead`: 18px, line height 1.625, then one `result` line, 16px gap) and chips. Parts are 16px apart, plus 8px of extra space above the chips (24px in all). The body fills the free height, so the chips always sit at the bottom of the card, whatever the length of the content, in the primary and the secondary cards alike (`flex flex-col`, body `flex-1`). Holds up to four chips; unused ones are hidden. The client name is plain small caps text.

Variants: `Type` primary (ink text, in a mint box with `radius-lg` and padding 24) and secondary (mint text, no result line, in a transparent box with a 1.5px mint border, used for "More work"). The layout is the same at every breakpoint, so there is no `Breakpoint` property: the block sets the width. Penpot name `work-card`. In Astro: `WorkCard` with a `type` prop (`primary` or `secondary`).
