External-link icon, 12px, 1.5px stroke, in the color of the surrounding text. Used after the author name in `quote` (the name links to the person's LinkedIn profile) after the "Read them all on LinkedIn" link in `recommendations-block`, and after the LinkedIn and GitHub links in `footer` (mint, like the text). Stroke color is overridden per instance: ink by default (`text.on-light`), mint on the featured card. Penpot name `icon-external-link`, Atoms section. In Astro, the SVG is the file `assets/icons/link-external.svg` (the site keeps a copy in `src/assets/icons/`), imported as a component by the `IconExternalLink` atom, using `currentColor`. Placement: at the end of the text, 8px from it, bottom edge on the text baseline. The link around it is `inline-flex items-baseline gap-2` and the icon is `inline-block align-baseline`. Penpot cannot flow an icon inside wrapped text, so there it sits at the bottom right of the name box.
