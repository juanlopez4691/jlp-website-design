External-link icon, 12px, 1.5px stroke, in the color of the surrounding text. Used after the author name in `quote-card` (the name links to the person's LinkedIn profile) and after the "Read them all on LinkedIn" link in `recommendations-block`. Stroke color is overridden per instance: navy by default, mint on the featured card. Penpot name `icon-external-link`, Atoms section. In Astro, an inline SVG using `currentColor`. Placement: inline at the end of the text, 8px after the last character, bottom edge on the text baseline (Tailwind: `ml-2 inline-block align-baseline`). Penpot cannot flow an icon inside wrapped text, so there it sits at the bottom right of the name box.
