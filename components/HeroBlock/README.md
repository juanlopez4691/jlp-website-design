Claim animation. The `h1` reads "I forge" plus a two-line sentence that cycles through four: "solid web solutions" (default), "web apps that scale", "web shops that sell", "performant websites", then back to the first. Each holds 2 s, then the next decodes in 700 ms: characters turn from random glyphs (a to z and symbols, redrawn every 45 ms) into the final letters, roughly left to right with a little jitter. Spaces never scramble. A scrambled glyph is never wider than the letter it hides, so lines never reflow; every sentence is exactly two lines after "I forge", and the `h1` reserves the height of the tallest. It pauses while off screen or while the tab is hidden (the current sentence shows settled). With `prefers-reduced-motion` there is no cycling and only the first sentence shows. Screen readers always read "I forge solid web solutions" (the animated text is `aria-hidden`). Penpot shows this on the board `spec / hero claim animation`, next to the variants.
