# Figma build guide

Design at 1280px wide, desktop first, with three more frames: 1024 (`lg`), 768 (`md`) and 390 (`base`). Each block is a full-width frame with vertical auto layout; inside it a 1152px container (fixed width, centred, 64px side padding at 1280; 960 and 32 at lg). The current Home is the page "05 v2. Home" (boards `Home V2 / xl 1280`, `Home V2 / lg 1024`, `Home V2 / md 768`, `Home V2 / base 390`). Page order: header, hero, facts, Services, quote, Selected work, Recommendations, How I work, Experience, Stack, Contact, footer.

Section headers (all blocks except hero, facts and quote) are the `section-header` component (1152 wide): eyebrow (`eyebrow`, 21px), then `h2` with no gap between them, 16px before the content, plus 32px of top padding on the content grid. Block vertical padding 80.

## Block structure and surfaces
Every block is the same shell: full-width frame (1280), vertical auto layout, 80px padding top and bottom (`space-20`; the header, facts and footer use 32), one 1152px `container` inside, and the Section arrow as an absolute child. The fill is bound to a `surface.*` token, never a raw colour: `surface.hero` (saffron: header, hero, recommendations), `surface.stack` (navy: facts, stack, footer), `surface.ground` (mint: services, experience), `surface.quote` (coral: quote), `surface.how` (coral: how I work), `surface.work` (teal: work, contact). Each block is a component (see Components below), and a Home board is a stack of block instances. The shell shared by all blocks is not a component of its own, because Penpot has no slots; in Astro it is one `Block` wrapper with a `surface` prop and a slot that each block component uses.

**Layer structure and names.** Top-level boards are named `Home V2 / <breakpoint> <width>`; inside, every block instance is named `block / <name>` (header, hero, facts, services, quote, work, recommendations, how, experience, stack, contact, footer). The `container` holds the content directly (a row or a column), with no extra wrapper of the same size. Grids are named `<content> grid` (`services grid`, `work grid`, `more work grid`, `quotes grid`, `steps grid`, `principles grid`, `stack grid`) and the experience list is `jobs list`. Text layers carry their role (`h1`, `role`, `tagline`, `lead`, `title`, `address`, `note`, `copyright`), arrows are `arrow / from <previous block>`, and background images are named for where they sit (`hero image`, `contact image`). Component names are flat kebab-case (`nav-link`, `nav-lang`, `tick`). Versions live in Penpot asset folders: the components of the V2 design are in the folder `V2` (component path, e.g. `V2 / hero-block`) with the same names as before, so the previous version (the component at the root, no folder) keeps working. Components that did not change stay at the root and are reused as they are. A future version would use a `V3` folder. Tech stack groups are plain boards named `stack / <name>`, not components, because a component copy cannot change its number of chips. Boards that hold a heading with tight leading (h1, h2, mail) do not clip their content, so descenders are never cut; only the blocks clip. Each block has a text label named `label / <component>` outside the boards (left of each Home board, above each variant set on the Components page) so a block can be referenced by name; labels are not part of the design. Hidden layers are only used on purpose: the author photo on tablet and phone, and chips or lines that a given card does not show.

## Components
The pages "01 v1. Components" (root components) and "04 v2. Components" (folder `V2`) have three levels, from small to large (Atomic Design): `Atoms`, `Molecules` and `Blocks`. Each component has its own section with a title, in the order it first appears on Home, and every variant set sits in one container.

- **Atoms** are single elements with no structure of their own: `brand`, `nav-link`, `nav-lang`, `menu-button` (and `menu-button-close`), `button`, `pill`, `eyebrow`, `tick`, `arrow` (the section arrow) and `icon-external-link`. V2 adds `step-arrow`.
- **Molecules** are small groups of atoms with one job: `fact`, `section-header`, `service-card`, `work-card`, `quote`, `step`, `principle` and `job-row`. They hold content only. The coloured box around a work card or a quote (fill or border, radius, padding) belongs to the block that uses it, so the same content can be reused on another surface. V2 adds `figure` and `work-card-featured`, and has its own `fact`, `step` and `work-card`.
- **Blocks** are the organisms, one per block of the page: `header`, `hero-block`, `facts-block`, `services-block`, `quote-block`, `work-block`, `recommendations-block`, `how-block`, `experience-block`, `stack-block`, `contact-block` and `footer`. A Home board is a stack of block instances.

The V2 set (page "04 v2. Components", asset folder `V2`) is `hero-block`, `facts-block`, `work-block`, `how-block`, `fact`, `figure`, `step`, `step-arrow`, `work-card` and `work-card-featured`. It reuses the root `section-header`, `eyebrow`, `pill`, `button`, `principle` and `arrow`. Every block, root or V2, has `Breakpoint` xl, lg, md and base. The Home (page "05 v2. Home", four boards) is built only from block instances: root `header`, V2 `hero-block`, V2 `facts-block`, root `services-block`, root `quote-block`, V2 `work-block`, root `recommendations-block`, V2 `how-block`, root `experience-block`, root `stack-block`, root `contact-block`, root `footer`. The page "02 v1. Home" and the root blocks that V2 replaced (for example the `hero-block` without folder) are the previous version (V1), kept for reference only.

Variant properties follow the design. `Breakpoint` (`xl`, `lg`, `md`, `base`; `lg` is 1024, with a 960 container and 32px side padding) exists where the look or the layout changes with the screen: every block, `fact`, `principle`, `job-row` (pill above the text on phones), `section-header` (title size) and `quote` (title size and hidden photo). Components that only change width have no `Breakpoint`: the block sets their width. Colour or kind variants use `Style`, `Tone`, `Type`, `Color` or `Position`: `quote` (`Style` featured or regular), `work-card` (`Type` primary or secondary), `section-header` (`Tone` on-light or on-dark), `button`, `pill`, `eyebrow`, `brand`, `service-card` and `job-row`. Variants that only show on a dark surface are repeated in a dark row below the set. The V2 `fact` and `figure` have no `Breakpoint`. Each component maps to one Astro component of the same name in PascalCase (`HeroBlock`, `SectionHeader`, `Quote`), so the Home page is a list of block components. Text trim: the site trims text boxes to cap height and baseline (`text-box: trim-both cap alphabetic`); Penpot cannot, so Penpot gaps are slightly smaller than the CSS gaps (hero column gap 20 for `gap-8`). Text overrides on an instance are the page content (the component defaults may still hold older copy); structure only changes in the main component.

## Section arrow
A pointed arrow (96 x 40, concave quarter-ellipse sides) hangs from the top edge of a block, centred, in the colour of the block above, so it reads as the previous block pointing into the next. Used on every block that follows a block of a different colour except the facts stripe and the footer. Absolute positioned, so it does not move the content.

## Header (own saffron block, above the hero)
A separate full-width block, not part of the hero. Saffron fill (`surface.hero`), 32px padding top and bottom, nav vertically centred, same 1152px container.
