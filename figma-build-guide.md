# Figma build guide

Design at 1280px wide, desktop first. Each block is a full-width frame with vertical auto layout; inside it a 1152px container (fixed width, centred, 64px side padding at 1280). Page order: header, hero, facts, What I do, quote, Selected work, Recommendations, How I work, Experience, Stack, Contact, footer.

Section headers (all blocks except hero, facts and quote) are the `section-header` component (1152 wide): eyebrow (`eyebrow`, 21px), then `h2` with no gap between them, 16px before the content, plus 32px of top padding on the content grid. Block vertical padding 80.

## Block structure and surfaces
Every block is the same shell: full-width frame (1280), vertical auto layout, 80px padding top and bottom (`space-20`; the header, facts and footer use 32), one 1152px `container` inside, and the Section arrow as an absolute child. The fill is bound to a `surface.*` token, never a raw colour: `surface.hero` (saffron: header, hero, recommendations), `surface.stack` (navy: facts, stack, footer), `surface.ground` (mint: services, experience), `surface.quote` (coral: quote), `surface.how` (coral: how I work), `surface.work` (teal: work, contact). Each block is a component (see Components below), and a Home board is a stack of block instances. The shell shared by all blocks is not a component of its own, because Penpot has no slots; in Astro it is one `Block` wrapper with a `surface` prop and a slot that each block component uses.

**Layer structure and names.** Top-level boards are named `Home / <breakpoint>`; inside, every block instance is named `block / <name>` (header, hero, facts, services, quote, work, recommendations, how, experience, stack, contact, footer). The `container` holds the content directly (a row or a column), with no extra wrapper of the same size. Grids are named `<content> grid` (`services grid`, `work grid`, `more work grid`, `quotes grid`, `steps grid`, `principles grid`, `stack grid`) and the experience list is `jobs list`. Text layers carry their role (`h1`, `role`, `tagline`, `lead`, `title`, `address`, `note`, `copyright`), arrows are `arrow / from <previous block>`, and background images are named for where they sit (`hero image`, `contact image`). Components are flat kebab-case names (`nav-link`, `nav-lang`, `tick`), with no folders. One exception: the V2 components live in a Penpot asset folder `V2` (component path, e.g. `V2 / hero-block`) and keep the same names as V1, so V1 pages keep working. Tech stack groups are plain boards named `stack / <name>`, not components, because a component copy cannot change its number of chips. Boards that hold a heading with tight leading (h1, h2, mail) do not clip their content, so descenders are never cut; only the blocks clip. Each block has a text label named `label / <component>` outside the boards (left of each Home board, above each variant set on the Components page) so a block can be referenced by name; labels are not part of the design. Hidden layers are only used on purpose: the author photo on tablet and phone, and chips or lines that a given card does not show.

## Components
The "01 Components" page has three levels, from small to large (Atomic Design): `Atoms`, `Molecules` and `Blocks`. Each component has its own section with a title, in the order it first appears on Home, and every variant set sits in one container.

- **Atoms** are single elements with no structure of their own: `brand`, `nav-link`, `nav-lang`, `menu-button` (and `menu-button-close`), `button`, `pill`, `eyebrow`, `tick`, `arrow` (the section arrow) and `icon-external-link`. V2 adds `step-arrow`.
- **Molecules** are small groups of atoms with one job: `fact`, `section-header`, `service-card`, `work-card`, `quote`, `step`, `principle` and `job-row`. They hold content only. The coloured box around a V1 work card or a quote (fill or border, radius, padding) belongs to the block that uses it, so the same content can be reused on another surface. Exception: the V2 work cards (`work-card`, `work-card-featured`) include their box. V2 adds `figure` and `work-card-featured`, and has its own `fact`, `step` and `work-card`.
- **Blocks** are the organisms, one per block of the page: `header`, `hero-block`, `facts-block`, `services-block`, `quote-block`, `work-block`, `recommendations-block`, `how-block`, `experience-block`, `stack-block`, `contact-block` and `footer`. A Home board is a stack of block instances.

The "05 V2 Components" page has the same three levels for the V2 set (asset folder `V2`: `hero-block`, `facts-block`, `work-block`, `how-block`, `fact`, `figure`, `step`, `step-arrow`, `work-card`, `work-card-featured`). V2 blocks reuse the V1 `section-header`, `eyebrow`, `pill`, `button`, `principle` and `arrow`. The page "04 Home V2" is a 1280 board built only from instances: V1 `header`, V2 `hero-block`, V2 `facts-block`, V1 `services-block`, V1 `quote-block`, V2 `work-block`, V1 `recommendations-block`, V2 `how-block`, V1 `experience-block`, V1 `stack-block`, V1 `contact-block`, V1 `footer`.

Variant properties follow the design. `Breakpoint` (`xl`, `md`, `base`; the V2 blocks also have `lg`, 1024, with a 960 container and 32px side padding) exists where the look or the layout changes with the screen: every block, `fact`, `principle`, `job-row` (pill above the text on phones), `section-header` (title size) and `quote` (title size and hidden photo). Components that only change width have no `Breakpoint`: the block sets their width. Colour or kind variants use `Style`, `Tone`, `Type`, `Color` or `Position`: `quote` (`Style` featured or regular), `work-card` (`Type` primary or secondary), `section-header` (`Tone` on-light or on-dark), `button`, `pill`, `eyebrow`, `brand`, `service-card` and `job-row`. Variants that only show on a dark surface are repeated in a dark row below the set. V2 `fact` and `figure` have no `Breakpoint`. Each component maps to one Astro component of the same name in PascalCase (`HeroBlock`, `SectionHeader`, `Quote`), so the Home page is a list of block components. Text trim: the site trims text boxes to cap height and baseline (`text-box: trim-both cap alphabetic`); Penpot cannot, so Penpot gaps are slightly smaller than the CSS gaps (hero column gap 20 for `gap-8`). Text overrides on an instance are the page content; structure only changes in the main component.

## Section arrow
A pointed arrow (96 x 40, concave quarter-ellipse sides) hangs from the top edge of a block, centred, in the colour of the block above, so it reads as the previous block pointing into the next. Used on every block that follows a block of a different colour except the facts stripe and the footer. Absolute positioned, so it does not move the content.

## Header (own saffron block, above the hero)
A separate full-width block, not part of the hero. Saffron fill (`surface.hero`), 32px padding top and bottom, nav vertically centred, same 1152px container. ## Phone (390px, `base`)
Same blocks in the same order, one column, built on `Home / base 390`. Side padding 32 (container 326), block vertical padding 64 (`space-16`), same `surface.*` fills, arrow centred (96 x 40 stays). Only the Display styles shrink (see "Display mobile" in `tokens.json`; tokens `font.size.*-base` and `font.tracking.*-base`): h1 48, h2 36, mail 30, quote-big 24; every other style keeps its desktop size.

- **Header:** "EN / ES" (`nav`) on the left, `menu-button` on the right, no nav links and no brand name (the name is in the hero title). The open menu is a second frame (`Menu / base 390 (open)`): saffron panel, same header with `menu-button-close` on the right, then the eight links in `h3-service` (24 gap).
- **Hero:** (V2) no image. Availability pill full width with shorter copy, "Open to freelance and full-time work" (keep it as a separate short string for i18n), tagline, `h1` at 60, role, lead, then the two buttons stacked at full width (gap 16, label centred). Column 326, 751 tall.
- **Facts:** (V2) two columns of 151, gap 24 across and 32 down. Items have auto height, never a fixed one. 501 tall.
- **Cards:** services and recommendations in a single column at full width, gap 24, card padding 24 on recommendation cards (no author photo); cards grow to fit their text. Chips wrap. V2 work: two stacked featured cards, four primary and three secondary cards in one column of 326, gap 24 (4624 tall).
- **Quote block:** decorative marks 128 wide in the corners, text left-aligned; author and role on separate lines (no leading dot).
- **How I work:** (V2) four steps stacked (gap 32), then the four principles stacked at full width 326 (gap 32); no workshop image. 2025 tall.
- **Experience:** the git log line stays on the left (32 wide); the date pill sits above the title and text. Each row is as tall as its content, so spine and tick follow it.
- **Stack:** groups stacked, chips wrap.
- **Contact:** title (h2 mobile) and address (mail mobile) stacked, buttons stacked at full width, text below. No background engraving on phones.
- **Footer:** one column, 32px apart, side padding 32. The two columns of site links sit side by side, then the column of LinkedIn, GitHub and Download my CV, then the legal links (16px on each side of the bullet), then the copyright. 409px tall.
