# lojopez.dev

Color blocks: a bright, flat system for the portfolio of Joan López, a senior full stack developer. Full-width blocks in saffron, coral, teal and navy, pill-shaped labels, square buttons and engravings, among them a woodcut of a blacksmith.

## Implementation

The site is built in Astro in a separate repository, [jlp-website](https://github.com/juanlopez4691/jlp-website). Its components use the names in this repository, and each spec here describes the matching component there.

## Content fundamentals

- First person, direct. "Hello, I'm Joan López." "I take care of the technical side, from architecture to launch, so your project works on day one and stays fast, secure and easy to maintain."
- Short sentences with concrete nouns: Statamic, WooCommerce, Laravel, TicketBAI. No sales language, no superlatives.
- No em dashes or en dashes. Dates read "Jan 2021 to Present".
- Sentence case for titles and buttons: "Get in touch", "Email me". Uppercase only for eyebrows, client tags and fact labels.
- Each work card states what was built, then one line of result in `result` weight.
- Every section has an eyebrow plus a title, and the two never repeat the same words: "Services" / "How I can help", "Selected work" / "Things I've built", "My process" / "How I work", "Experience" / "25+ years building for the web".
- Quotes on the page are fragments taken from real recommendations, with the author named.

## Visual foundations

**Color.** Mint is the ground. Each block takes one color: saffron (hero and recommendations), mint (services and experience), teal (work and contact), coral (quote and how I work), navy (facts and stack), ink (footer). Text on saffron, coral and mint is `ink`. Text on teal, navy and ink is `mint`. `saffron` is also the accent on navy and teal: core chips, the availability dot, the contact address, the stack labels.

**Shape.** Small labels are pills (`radius-full`): chips, fact pills, date pills. The client name on a work card is plain uppercase text in the `tag` style, not a pill. Buttons are square (`radius-none`, 0) so they never read as labels. Service cards round two opposite corners (`radius-48`, 48px, top right and bottom left). Each block after a block of a different colour starts with a pointed arrow in the previous block's colour (the Section arrow), so one block points into the next. Work cards use `radius-48` on two opposite corners, like service cards (the box belongs to the work block; the previous version had nearly square `radius-lg` cards). All recommendation cards, featured or regular, share one radius (`radius-28`, 28px). Radius token names follow Tailwind: `radius-lg` is `rounded-lg`, `radius-full` is `rounded-full`, `radius-none` is `rounded-none`. The two values Tailwind has no class for are written as `rounded-[28px]` (`radius-28`) and `rounded-[48px]` (`radius-48`).

**Type.** Familjen Grotesk (700, tight tracking) for display and titles. Figtree for text, labels and buttons, for the contact address at weight 400 (`mail`) and for the featured quote at weight 400 (`quote-big`). Both from Google Fonts. Sizes are Tailwind defaults, except the hero: the tagline "Hello, I'm Joan López. Senior web developer." is 20px (`font.size.text-xl`, bold, line height 1.25) and the `h1`, "I forge" plus a cycling two-line sentence, is 80px at xl, 72 from 640 (`sm`) up to xl and 56 below 640 (`font.size.hero`, `hero-md`, `hero-base`; line height 0.9, tracking -2, -1.8 and -1.4). The step numbers of How I work are 176px (`font.size.step-number`, tracking -7.04). h2 is `text-6xl` (60px), role and card titles `text-2xl` (24px), hero lead `text-lg` (18px). The `font.size.h1` token (96, with `h1-md` 60 and `h1-base` 48) and the `Display/h1` style are only used by the V1 hero and the Foundations specimen. Text in pills and tags is always 14px (`pill`, `label`, `tag`); navigation text is always 16px (`nav`). Titles tighten as they grow: hero -2px tracking, h2 -1.5px.

**Long-form pages.** Blog, case studies and legal pages use the `Content` styles: h1 to h6 in Familjen Grotesk 700, body in Figtree 18px with line height 1.5, a 65ch reading column at the left of the container, and the prose rules in `tokens.json`. Everything maps to default Tailwind classes (`text-lg leading-normal`, `max-w-prose`, `space-y-6`). Sizes step at breakpoints instead of scaling fluidly, so Tailwind needs no custom values. Only the Display styles shrink (each size has a `font.size.*` and `font.tracking.*` token per breakpoint, bound to the text in Penpot): desktop sizes from `xl` (1280px), `Display tablet` from `md` (768px) up to `xl` (hero 72, h2 48, mail 48, quote-big 30) and `Display mobile` below `md` (hero 56, h2 36, mail 30, quote-big 24). The hero is the one exception: it takes its tablet size from 640 (`sm`), not from `md`. There are four frames, 1280, 1024 (`lg`, container 960), 768 and 390; at `lg` the hero uses its `md` size and the `section-header` its `md` variant. Versions live in Penpot asset folders: the components of the current design are in folder `V2` (page "04 v2. Components"); components that did not change stay at the root (page "01 v1. Components"). The current Home is page "05 v2. Home"; "02 v1. Home" is the previous one.

**Layout.** One container (`container`, 1152px) inside full-bleed blocks. Blocks use `space-20` vertical padding. Cards sit in auto-fit grids with a `space-5` gap. Hero: text left and engraving right from `lg` (tablet and phone have no hero image; transparent woodcut, navy ink, fills the rest of the row at the height of the text column, cropped to cover). Under the hero, a full-width navy stripe holds the key facts, inside the same container: two figures and three facts. Every block has an `lg` step at 1024 with a 960px container and 32px side padding. Cards in one row share the height of the tallest card. Below `md` the services, the non-featured work cards (selected and more, two sliders) and the regular recommendations are sliders with `slider-dots`, and experience is a horizontal timeline, so the page stays short; services show two columns from 620 and the rest two from 680 (the only two widths outside the Tailwind defaults, see `components/SliderDots/README.md`). In every card the last part stays pinned to the bottom, whatever the length of the content: the pills of a work card (including the outline "More work" cards) and the author name and role of a recommendation. The text above takes the free height (`flex flex-col`, body `flex-1`).

**Imagery.** Three engravings, all dark line on transparent, never inverted, all from Wikimedia Commons. The hero (from `lg`, cropped to cover) uses a woodcut of a blacksmith at the anvil: [Blacksmith at the anvil (Wellcome L0005875)](https://commons.wikimedia.org/wiki/File:Blacksmith_at_the_anvil._Wellcome_L0005875.jpg), from William Gilbert's De Magnete (1600), licensed CC BY 4.0. The contact block (desktop and tablet, hidden on phones) uses [Fig 25 Gentleman with two telephones 1880](https://commons.wikimedia.org/wiki/File:Fig_25_Gentleman_with_two_telephones_1880.jpg), an illustration by B. Bonnafoux from Théodose du Moncel's Le téléphone, le microphone et le phonographe (1880), in the public domain. It looks faint because the contact block is dark teal, not because of any opacity. Edits to the originals: the blacksmith is trimmed to the figure and both have the solid background removed, nothing else. The edited files live in `jlp-website/src/assets/`: the blacksmith file is 1314x1044 and the telephones file is 1256x1190, both 2x their display boxes. The blacksmith is CC BY 4.0, so the site must credit it, link the licence and say that it was trimmed and had its background removed. The telephones image needs no credit, but the credits page names its author and book anyway. The third engraving is the workshop, used by the how block at xl and lg: [Fig. 248 "Glaspuster ved Lampen"](https://commons.wikimedia.org/wiki/File:Opfindelsernes_bog5_fig248.png) (a glassblower at the lamp) from André Lütken's Opfindelsernes Bog, vol. V (1880), scan uploaded by Morten Bisgaard. It is in the public domain (Public Domain Mark 1.0), so no credit is required, but the credits page lists it with the other engravings. The site file `workshop.webp` is 912x1392, 3x its 304x464 display box, cropped from the 3500x3500 original; dark line, not inverted.

**No** gradients (the one exception is the scroll fade of long-form tables and code blocks), shadows (the one exception is the pinned header, once the page has scrolled), icons or emoji. Depth comes from color fields and borders (`2px` ink outlines, `1.5px` mint on dark blocks).

## Iconography

One exception: a small external-link icon, `icon-external-link` (12px, 1.5px stroke, same color as the text, 8px gap) after the author name in recommendation cards, to show that the name links to their LinkedIn profile. No other icons. The pill label does the job of an icon elsewhere.

## Using this in Figma

1. Install the Tokens Studio for Figma plugin. Load `assets/Figma/tokens-studio.json` (Settings, Add new, JSON). Create styles for colors and text, and variables for spacing and radius.
2. Install the fonts Familjen Grotesk (500, 600, 700) and Figtree (300, 400, 500, 600) from Google Fonts.
3. Build the page at 1280px wide with the layout in the "Figma build guide" section: auto layout everywhere, container 1152px, blocks as full-width frames.
4. Components to create first: Button (primary, secondary, primary-on-dark, secondary-on-dark), Pill (chip, date, fact, availability), Section arrow, Section header, Menu button, Step, Quote block, Service card, Work card, Job row, Quote. Each has a live preview and a spec in this system.
